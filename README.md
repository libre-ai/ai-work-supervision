# Libre AI Work Supervision

Keep track of work entrusted to AI agents without losing sight of what you asked for, what is blocked and what has actually been completed. This proposed product is for people coordinating work with agents who need a clear place to review progress and make decisions.


## Intended uses

- Describe an assignment and the result you expect before work starts.
- See which tasks are progressing and which need your input.
- Compare a reported result with supporting evidence before accepting it.
